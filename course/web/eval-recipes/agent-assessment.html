The system under assessment — Meridian Commercial Bank "Apex" desk

One orchestrator + six subagents. Each metric below is a real example tied to a named agent. Agent definitions live in .claude/agents/*.md.

Every card links to a runnable test script (scripts/<metric-id>.eval.ts) that evaluates that metric on healthy fixtures and prints PASS ✓ / FAIL ✗ with a non-zero exit on failure — CI-ready. Run one with npx tsx scripts/<metric-id>.eval.ts, or all of them via scripts/README.md.
