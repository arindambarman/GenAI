The engineered core. The same pipeline runs from the full tutor.html page and the floating Ask widget. It dogfoods the course's own metrics — every answer is self-scored (citation-faithfulness, schema-conformance, refusal correctness, latency, cost) and emits a 5-span trace viewable in Trace Explorer.

User-experience journey

learn → practice → master

Wherever a learner is — reading a lesson, exploring the graph, or running a live eval — the Ask bubble is one tap away. Every tutor answer links back into content (lesson citations, related re-asks) and forward into tools (open this answer's trace). The tutor never invents — it cites or refuses.
