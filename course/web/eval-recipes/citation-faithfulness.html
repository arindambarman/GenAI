Citation faithfulness eval

Output correctness

correctness intermediate
When to use: Any RAG, document-grounded, or citation-emitting agent — before shipping and on every prompt change.
What it measures: The fraction of model claims that are verifiable against the cited source span.

Setup

  1. Sample 200 production queries stratified by topic and answer length.
  2. Parse each output into (claim, citation_span) pairs.
  3. Use LLM-judge to label each pair: verified | partially_verified | unsupported | contradicted.
  4. Compute weighted score: verified=1.0, partial=0.5, unsupported=0, contradicted=-1.
  5. Calibrate against human raters on 50 pairs; re-calibrate after every retrieval index change.

Code template

typescriptconst CitationVerdict = z.enum(["verified", "partial", "unsupported", "contradicted"]);
const ClaimResult = z.object({
  claim: z.string(),
  source_span: z.string(),
  verdict: CitationVerdict,
  note: z.string().optional(),
});

export async function evalCitations(answer: AgentAnswer): Promise<number> {
  const pairs = extractClaimCitationPairs(answer);
  const verdicts = await Promise.all(pairs.map((p) =>
    judgeClaim(p.claim, p.source_span)
  ));
  const score = verdicts.reduce((acc, v) => acc + {
    verified: 1, partial: 0.5, unsupported: 0, contradicted: -1,
  }[v.verdict], 0) / Math.max(verdicts.length, 1);
  return score;  // [-1, 1]
}

Flow

graph LR
  ANS[Agent answer<br/>+ citations] --> EXT[Extract<br/>claim/source pairs]
  EXT --> JUDGE[LLM Judge<br/>per pair verdict]
  JUDGE --> SCORE[Weighted score]
  SCORE --> GATE{>= 0.95?}
  GATE -->|yes| SHIP[Ship]
  GATE -->|no| BLOCK[Block + alert]

Acceptance threshold

Weighted score ≥ 0.95; zero contradicted claims; ≤ 1% unsupported.

Pitfalls

⚠️ Citations point to right doc, wrong page
Fix: Score at page+character granularity, not document-level.
⚠️ Drift after retrieval index rebuild
Fix: Make citation faithfulness eval a required gate on the indexing pipeline, not just the agent.
⚠️ Multi-sentence claims with partial support score as verified
Fix: Split into atomic claims before judging.
