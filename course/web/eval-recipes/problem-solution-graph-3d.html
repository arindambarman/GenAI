Start here — finding the right AI strategy

This is a 3D map: a problem broken into questions (left/amber side) bridged to a solution (right/green side). Navigate it in four steps.

  1. Follow the numbers. Every node is numbered in reading order: 1–20 frame the problem (node 1 is the problem; the six questions are 2→7), and 21–41 build the solution. Start at 1.
  2. Watch the approach. Press 🎬 Walkthrough → "Approach" for a narrated tour of those six questions and their constraints, criteria, and pitfalls.
  3. Map to the solution. Run "Map problem → solution" — each question lights up the component that answers it across a green/gold bridge.
  4. Pressure-test & explore. Run "De-risk", then click any node for detail (Inspect / Explode / Trace), or 📱 Open in VR.
