Product catalog enrichment from images

Acme Merchandising · E-commerce

Multi-modal intermediate

Situation

Acme onboards 12,000 new SKUs per week from 800+ sellers. Each SKU needs: standardized title, 5-attribute structured spec, 3-bullet description, and category mapping. Current ops team handles 4,500/week; the remainder ship with minimal metadata and rank poorly in search.

Problem

Auto-enrich 100% of new SKUs from supplier-provided images + raw text within 4h of upload, hitting parity with human-curated SKUs on click-through rate (CTR).

Approach

  1. Vision blocks: pass up to 5 product images + raw supplier text to Sonnet in one request.
  2. Structured output via JSON Schema with category-conditional fields (sports & outdoors has different attributes than home & kitchen).
  3. Cached category schema + brand voice prompt as the prefix; cuts input cost ~80% across the day's batch.
  4. Batch API for the daily enrichment run — 4h SLA is fine since SKUs are scheduled to go live the next morning.
  5. Quality check: a second pass (Haiku) compares the enriched fields against the original images and flags mismatches for human review.
  6. Weekly regression eval: compare CTR on auto-enriched SKUs vs human-curated; tune prompts if gap > 5%.

Trade-offs (what we ruled out)

Ruled out: Real-time enrichment on upload
Sellers upload in spikes; batch saves 50% and the 4h SLA is invisible to sellers.
Ruled out: Single-pass with no quality check
10% flag rate justifies the second-pass cost; without it, supplier complaints triple.
Ruled out: Haiku-only
Vision quality on Haiku misses product-attribute nuances (fabric, finish); Sonnet is worth the bump.

Eval criteria

100% of new SKUs enriched within 4h · Attribute accuracy ≥ 92% (human spot-check, 200 SKUs/week) · CTR on auto-enriched SKUs within 5% of human-curated · Seller complaints ≤ current baseline.

Rollout plan

Backfill 50K archived SKUs and compare to existing data (2 weeks) → parallel on 10% of new (4 weeks) → full traffic with merchandiser review on flags (ongoing).
