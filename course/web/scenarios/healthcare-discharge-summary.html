Discharge summary drafting (safety-critical)

Regional hospital network · Healthcare

Safety-critical advanced

Situation

Hospitalists spend 45 minutes per patient drafting discharge summaries by stitching together notes, labs, and medication lists. Quality is uneven, follow-up instructions get lost, and 30-day readmission rates are sensitive to discharge clarity. Burnout is the top staffing risk.

Problem

Produce a draft discharge summary in 90 seconds that the hospitalist edits in ≤ 8 minutes. Zero tolerance for hallucinated medications, dosages, or follow-up dates.

Approach

  1. Privilege separation (CaMeL pattern): a planner agent assembles the input bundle from EHR tools; the drafting agent has NO direct EHR access — it only writes from the structured bundle.
  2. Strict tool use over the EHR with capability tokens scoped to the specific patient encounter only.
  3. Native PDF + Citations API for radiology reports and external referrals so every quoted figure links to its source.
  4. Extended Thinking enabled for the medication reconciliation step (the highest-risk section).
  5. A separate verification agent re-checks every medication and dosage against the structured bundle; mismatches block the draft from being returned.
  6. Hospitalist edits in-place; the diff is captured as eval signal and fed back to the regression set.
  7. Append-only audit log with model version, prompt hash, source data hash — sufficient for HIPAA disclosure and malpractice defense.

Architecture

Trade-offs (what we ruled out)

Ruled out: Single agent with EHR access
Prompt injection in pasted external notes is a realistic vector; CaMeL is the only safe pattern for safety-critical.
Ruled out: Auto-sign without hospitalist review
Legal and patient-safety non-starter; the goal is time savings, not autonomy.
Ruled out: Skip the verification agent
One missed medication is one too many; the 2nd-agent cost is trivial compared to harm risk.

Eval criteria

Hospitalist edit time ≤ 8 min p75 (vs 45 min baseline) · Zero medication hallucinations in 1000-case eval · Citation faithfulness ≥ 99% · 30-day readmission rate non-inferior to baseline at 6 months.

Rollout plan

Read-only shadow mode (drafts generated but invisible to hospitalists, 3 months) → side-by-side comparison (3 months) → hospitalist opts in (12 months) → default-on with opt-out (ongoing).
