KYC document review at scale

HSBC Mid-Office · Banking

Multi-modal intermediate

Situation

HSBC's mid-office processes 8,000 corporate KYC packages per month. Each package contains 30–80 PDFs (incorporation docs, UBO statements, sanctions screening). Analysts spend 40 minutes per package extracting and verifying fields against a 120-item checklist. Compliance failure rate is 6%, attracting regulatory attention.

Problem

Cut analyst time per package by 70% while keeping false-clear rate under 0.5% (regulator hard limit). Every decision must be auditable to SR 11-7 model risk standards.

Approach

  1. Use Claude's native PDF blocks (no OCR pre-step) so the model sees tables and stamps in context.
  2. Apply the Citations API to every extracted field so each value links back to a page+character range in source PDFs.
  3. Run Extended Thinking on the 12 highest-risk fields (UBO chain, sanctions match, jurisdiction); skip for routine fields to control cost.
  4. Use prompt caching on the 8-page checklist policy prompt (reused across all packages, saves ~85% on input cost).
  5. Route routine packages to Haiku, escalate complex ones to Sonnet via a tier-routing classifier.
  6. Log every decision to an append-only audit table (input hash, model version, prompt hash, output, analyst override) for SR 11-7 evidence.
  7. Human reviews every flagged item + a 5% random sample of approved ones; this becomes the regression eval set.

Trade-offs (what we ruled out)

Ruled out: Pre-OCR with Textract then send text to Claude
Loses layout/table fidelity; stamps and signatures missed. Native PDF blocks score 14 points higher on internal eval.
Ruled out: Single Opus model for everything
5x cost with only 2-point quality lift on routine packages; tier routing captures most of the benefit.
Ruled out: Full autonomous approval
Regulator requires human-in-the-loop for first 12 months; design accordingly rather than retrofit.

Eval criteria

Per-field accuracy ≥ 98% (sample of 500 packages, dual analyst grading) · False-clear rate ≤ 0.5% · Citation faithfulness ≥ 95% · Average wall-clock per package ≤ 12 min.

Rollout plan

Shadow mode (1 month, no impact on workflow) → Assist mode (analyst sees suggestions, 2 months) → Auto-approve routine + flag complex (6 months, with quarterly model risk review) → Re-baseline annually.
