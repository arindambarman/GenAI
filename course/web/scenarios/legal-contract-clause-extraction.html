Contract clause extraction with citations

Mid-size law firm · Legal

Multi-modal intermediate

Situation

M&A due diligence requires extracting 40+ clause types (change-of-control, IP assignment, indemnity caps, etc.) from 300–800 contracts per deal. Junior associates spend 60h per deal at $200/h, with 8% miss rate on subtle clauses.

Problem

Extract all required clauses with citations to page+paragraph, hit 98% recall on a curated test set of 50 contracts, and produce a deal-ready summary table in 4 hours instead of 60.

Approach

  1. Native PDF blocks (most contracts are scanned or have OCR issues; native PDF preserves layout).
  2. One Claude call per contract with the clause taxonomy + extraction schema cached at the prompt prefix.
  3. Citations API generates page+character refs for every extracted clause — these become hyperlinks in the deal report.
  4. Batch API for cold processing (overnight): 50% cheaper, 6h SLA fits the deal timeline.
  5. A second-pass verification agent (Haiku) re-reads each extraction against the cited span; mismatches go to associate review.
  6. Regression eval: a frozen set of 50 contracts with known clause annotations, run on every prompt change.
  7. Audit log captures source hash, model version, prompt version — admissible as work-product evidence.

Trade-offs (what we ruled out)

Ruled out: Real-time (interactive) extraction
Deal timelines accept overnight processing; batch saves 50%.
Ruled out: OCR pre-step
Layout matters for clause boundary detection; native PDF wins by 11 points on the eval set.
Ruled out: Single-pass without verification
8% flag rate is the cost of confidence; without it, partners audit every clause and the time savings evaporate.

Eval criteria

Recall ≥ 98% on the 50-contract eval (curated by partners) · Precision ≥ 95% · Citation faithfulness 100% (regulator/court-ready) · Deal turnaround 4h vs 60h baseline.

Rollout plan

Replay 3 historical deals with known outcomes (4 weeks) → live on next deal with partner sign-off on table (6 weeks) → default-on with associate review on flags only (ongoing).
