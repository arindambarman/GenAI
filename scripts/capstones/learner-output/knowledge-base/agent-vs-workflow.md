# Agent vs. Workflow vs. Pipeline Distinction

**Category:** foundational  ·  **Importance:** 10/10
**Introduced in:** Lesson 1.3

## Definition
A three-way taxonomy: Pipeline = fixed sequence of transforms with no LLM decisions; Workflow = branching logic with some LLM steps but a pre-specified control flow; Agent = LLM decides the control flow dynamically at runtime. The critical insight is that most tasks are over-engineered as agents.

## Notes
"The most common mistake: using an agent when a workflow would do" — stated course learning objective. Referenced in Module 11 business cases.

## Related concepts
- uses ← `five-question-framework` (The five-question framework is the operational decision tool that implements the agent-vs-workflow-vs-pipeline distinction in practice.)
- uses ← `agency-dial` (The agency dial provides the underlying continuous measure that the agent-vs-workflow distinction discretizes into three named categories (pipeline, workflow, agent).)
