# Cite-Faithfulness

**Category:** operational  ·  **Importance:** 7/10
**Introduced in:** Lesson 1.1

## Definition
The requirement that every factual claim made by an agent must trace to a specific, verifiable source (paper, document, page). Critical in high-stakes domains like biomedical research (Helix scenario) where hallucinated citations can derail expensive experiments. Distinguished from general accuracy: a claim can be true but still fail cite-faithfulness if its source is not explicitly traceable. Represents a hard constraint on agent output quality, not a soft preference.
