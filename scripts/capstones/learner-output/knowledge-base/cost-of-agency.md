# Cost of Agency

**Category:** foundational  ·  **Importance:** 9/10
**Introduced in:** Lesson 1.1, Lesson 1.3

## Definition
The set of drawbacks that increase with the agency dial: latency (more steps = more time), cost (more LLM calls = more tokens = higher spend), unpredictability (harder to test, audit, and guarantee behavior), and error compounding (mistakes cascade across multi-step chains). Justifies the heuristic "use the lowest dial setting that solves the problem."

## Notes
Directly motivates the decision framework in 1.3. Also connects to Module 9 (cost optimization) and Module 8 (eval).
