# Four Properties of an LLM Agent

**Category:** foundational  ·  **Importance:** 9/10
**Introduced in:** Lesson 1.1

## Definition
The four defining properties that distinguish an LLM agent from a plain chatbot or pipeline: (1) LLM as the core reasoning/planning engine, (2) tool use — ability to call external functions and APIs to affect the world, (3) memory — state that persists beyond a single LLM call, (4) goal-directedness — pursuing multi-step objectives rather than responding to one prompt.

## Notes
Acts as the specification checklist for classifying any system on the agency dial.
