# LLM Agent Era (2022+)

**Category:** foundational  ·  **Importance:** 7/10
**Introduced in:** Lesson 1.2

## Definition
The current generation of AI agents, emerging after the GPT-3/ChatGPT breakthrough (2020–2022), characterized by LLMs as general-purpose reasoning engines that can use tools, maintain context, and exhibit emergent planning behaviors without explicit programming. Key milestones: ReAct paper (2022), AutoGPT (2023), function calling APIs (2023).

## Notes
The end-point of the three-era historical narrative in Lesson 1.2. Explains why LLM agents are architecturally different from both symbolic and RL agents.

## Related concepts
- precedes ← `rl-agents` (RL agents represent the second historical era (1990–2017) that directly precedes and informs the LLM agent era (2022+), contributing key formalisms and evaluation mindsets.)
- precedes → `react-paradigm` (The LLM agent era enabled ReAct (Yao et al., 2022) as one of its first formalized agent paradigms, making the era a prerequisite context for understanding why ReAct emerged.)
