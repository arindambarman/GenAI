# LLM Agent Era (2022+)

**Category:** foundational  ·  **Importance:** 8/10
**Introduced in:** Lesson 1.2

## Definition
The current generation of agents that use large language models as the reasoning engine, inheriting zero-shot/few-shot generalization from pre-training. Key enablers: instruction-following capability, in-context learning, tool-use via function calling (2023+), and long-context windows. LLMs allow agents to be built without reward engineering or domain-specific training, dramatically lowering the cost of agent construction.

## Notes
Explains why this course exists now. Key insight: LLMs absorb the "world knowledge" that symbolic agents needed to hard-code.
