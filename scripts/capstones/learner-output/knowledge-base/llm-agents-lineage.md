# LLM Agents Era (2022+ Lineage)

**Category:** foundational  ·  **Importance:** 9/10
**Introduced in:** Lesson 1.2

## Definition
The current era of agents powered by large language models (Transformers) that leverage pre-trained reasoning and language understanding to operate in open-world problems without explicit training, using in-context learning and tool interfaces instead of learned policies.

## Notes
Modern paradigm; borrows MDP/POMDP concepts but applies them via prompting not learning. Module objective 2.

## Related concepts
- extends → `rl-agents-lineage` (LLM agents inherit conceptual frameworks from RL agents (MDPs, multi-step reasoning) but substitute learned policies with in-context prompting and pre-trained knowledge.)
