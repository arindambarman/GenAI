# Paradigm Comparison Matrix

**Category:** foundational  ·  **Importance:** 7/10
**Introduced in:** Lesson 1.4

## Definition
A structured comparison of ReAct, Reflexion, Plan-and-Solve, and CodeAct across dimensions: reasoning style, memory requirements, failure modes, best-fit tasks, and latency/cost profile. Used as a decision tool for selecting the right paradigm for a given use case. E.g., ReAct for interleaved tool use; Reflexion for trial-and-error tasks with feedback; Plan-and-Solve for long-horizon structured tasks; CodeAct for data manipulation tasks.

## Notes
Practical synthesis tool. Should include explicit failure modes per paradigm to help students avoid known pitfalls.
