# Paradigm Failure Modes

**Category:** foundational  ·  **Importance:** 7/10
**Introduced in:** Lesson 1.4

## Definition
Each major paradigm (ReAct, Reflexion, Plan-and-Solve, CodeAct) has characteristic failure modes: ReAct may loop endlessly; Reflexion may not learn from poor feedback; Plan-and-Solve may create brittle, non-adaptive plans; CodeAct may execute unsafe or inefficient code.

## Notes
Important for engineering resilience. Learning objective explicitly mentions recognizing and avoiding these modes. Supports decision-making on paradigm selection.

## Related concepts
- specializes → `react-paradigm` (Each paradigm's failure modes are characteristics of that implementation; ReAct's loop risks exemplify the general concept.)
- specializes → `reflexion-paradigm` (Reflexion's failure mode (poor learning from weak feedback) is tied to its core mechanic of learning from past attempts.)
