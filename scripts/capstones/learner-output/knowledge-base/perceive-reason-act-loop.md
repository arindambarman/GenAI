# Perceive-Reason-Act Loop

**Category:** foundational  ·  **Importance:** 9/10
**Introduced in:** Lesson 1.1, Lesson 1.2

## Definition
The fundamental cognitive cycle of any agent: (1) Perceive — receive inputs from the environment (sensor readings, API responses, user messages), (2) Reason — process inputs to form a plan or decision (LLM inference in modern agents), (3) Act — execute an action that changes the environment (tool call, response, file write). This loop repeats indefinitely or until a goal is reached. The loop is the atomic unit of agent behavior across all paradigms.

## Notes
Bridges classical AI (Russell-Norvig) to modern ReAct. Every paradigm in 1.4 is a specific instantiation of this loop.
