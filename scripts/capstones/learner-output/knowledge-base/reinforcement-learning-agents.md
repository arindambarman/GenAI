# Reinforcement Learning Agents (1990-2017)

**Category:** foundational  ·  **Importance:** 8/10
**Introduced in:** Lesson 1.2

## Definition
Agent systems trained via interaction with environments, using reward signals to learn value functions and policies. Formalized via MDPs/POMDPs; enabled breakthrough achievements like game-playing (Go, Chess) but struggled with sparse rewards and real-world complexity.

## Notes
Bridges symbolic agents to modern LLM agents. Introduces MDP formalism (forward-referenced to Module 2) and reward-based learning. Most progress in game domains; poor on open-ended tasks.

## Related concepts
- extends ← `llm-agents` (LLM agents leverage RL intuitions (MDPs, reward signals via prompting, exploration) while replacing explicit policy learning with in-context learning from large pre-trained models.)
