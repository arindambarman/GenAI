# RL Agents (1990-2017 Lineage)

**Category:** foundational  ·  **Importance:** 8/10
**Introduced in:** Lesson 1.2

## Definition
The historical era of agents built on reinforcement learning (Q-learning, policy gradients, actor-critic) that learn by trial-and-error in simulatable environments; influential for multi-step reasoning but limited by sample efficiency and environment simulability constraints.

## Notes
Explains concepts like MDPs, value functions, that resurface in reasoning. Forward references to Module 2 (MDP/POMDP). Module objective 2.

## Related concepts
- extends ← `llm-agents-lineage` (LLM agents inherit conceptual frameworks from RL agents (MDPs, multi-step reasoning) but substitute learned policies with in-context prompting and pre-trained knowledge.)
- extends → `symbolic-agents-lineage` (RL agents extended symbolic agents by replacing fixed logical rules with learned policies trained on reward signals from experience.)
