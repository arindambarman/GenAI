# Reinforcement Learning Agents (1990–2017)

**Category:** foundational  ·  **Importance:** 6/10
**Introduced in:** Lesson 1.2

## Definition
Agents that learn policies by maximizing cumulative reward through interaction with an environment (e.g., TD-Gammon, AlphaGo, Atari DQN). Formally modeled as MDPs. Key contribution: the concepts of state, action, reward, and policy — which persist into modern LLM agent design. Key limitation: require massive interaction data and do not transfer well across domains.

## Notes
MDP formalism carried forward into Module 2 (Mathematical Foundations). Provides the vocabulary of state/action/reward used throughout.
