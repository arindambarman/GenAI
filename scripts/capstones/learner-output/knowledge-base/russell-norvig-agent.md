# Russell-Norvig Agent Definition

**Category:** foundational  ·  **Importance:** 6/10
**Introduced in:** Lesson 1.1

## Definition
Classic AI textbook definition: an agent is anything that perceives its environment through sensors and acts upon it through actuators to maximize a performance measure. Foundation for modern agent thinking but predates LLMs.

## Notes
Historical anchor — the course uses it to show continuity from classical AI to LLM agents.
