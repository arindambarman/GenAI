# Symbolic Agents (1956-1990 Lineage)

**Category:** foundational  ·  **Importance:** 7/10
**Introduced in:** Lesson 1.2

## Definition
The historical era (Newell & Shaw, McCarthy) of agents built on explicit logical rules, planning algorithms (STRIPS, GraphPlan), and knowledge representation in closed domains; foundational but replaced by RL and later LLM approaches for open-world problems.

## Notes
Historical context; explains why classical planning is less relevant for LLM agents. Module objective 2.

## Related concepts
- extends ← `rl-agents-lineage` (RL agents extended symbolic agents by replacing fixed logical rules with learned policies trained on reward signals from experience.)
