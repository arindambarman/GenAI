# Symbolic Agents (1956–1990)

**Category:** foundational  ·  **Importance:** 7/10
**Introduced in:** Lesson 1.2

## Definition
Early AI agents based on explicit symbolic logic, rule engines, and knowledge bases (e.g., STRIPS planner, MYCIN expert system). They encode world knowledge as hand-crafted rules and search over symbol structures. Key limitation: brittleness — they fail outside the narrow domain of their rules, and knowledge engineering is expensive. Key survival: the idea of explicit planning and structured state representation.

## Notes
Historical context; explicit planning survives in Plan-and-Solve paradigm (lesson 1.4).

## Related concepts
- extends ← `llm-agents` (Modern LLM agents inherit the planning and reflection concepts from symbolic agents (1950s-1990s), but replace hand-coded logic with learned representations.)
