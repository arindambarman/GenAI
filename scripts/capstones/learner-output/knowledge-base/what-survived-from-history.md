# Surviving Ideas from Agent History

**Category:** foundational  ·  **Importance:** 6/10
**Introduced in:** Lesson 1.2

## Definition
Key concepts that migrated from symbolic and RL agents into LLM agents: (1) from symbolic AI — knowledge representation (now: tool schemas, system prompts), search and planning algorithms; (2) from RL — reward/evaluation thinking (now: evals), MDP formalism, exploration vs. exploitation trade-off.

## Notes
Provides intellectual justification for why Module 2 (math foundations) uses MDP/POMDP formalisms even for LLM agents.

## Related concepts
- uses → `rl-agents` (The 'surviving ideas' concept draws specifically on RL agent contributions (MDP, reward/evaluation, exploration) as the lineage into modern LLM agent design.)
