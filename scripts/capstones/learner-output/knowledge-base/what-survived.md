# Ideas That Survived the AI Paradigm Shifts

**Category:** foundational  ·  **Importance:** 7/10
**Introduced in:** Lesson 1.2

## Definition
Concepts that proved durable across symbolic → RL → LLM agent eras: (1) explicit state representation (now: context window + memory), (2) planning (now: Plan-and-Solve, CoT), (3) tool use / actuation, (4) evaluation against ground truth, (5) the perceive-reason-act loop. Understanding what survived helps practitioners avoid re-inventing solved problems and correctly apply historical lessons.

## Notes
The "what survived" framing prevents cargo-culting. Shows intellectual lineage for ReAct, Plan-and-Solve, etc.
