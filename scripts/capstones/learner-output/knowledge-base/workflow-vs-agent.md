# Workflow vs Agent Decision Framework

**Category:** foundational  ·  **Importance:** 9/10
**Introduced in:** Lesson 1.3

## Definition
A five-question decision heuristic for choosing between predefined workflows (fixed step sequences, no loops), pipelines (linear data transformation), and agents (adaptive, feedback-loop-driven architectures). Emphasizes cost of agentification and when NOT to use agents.

## Notes
Critical decision framework for practitioners. Prevents over-engineering simple problems. Mentions 'cost of agency' and vendor choices. Forward-referenced to Module 11 (business cases).

## Related concepts
- uses → `agency-dial` (The decision framework uses the agency dial (and cost considerations) to guide practitioners on whether to invest in agent-level autonomy or stick with workflows.)
